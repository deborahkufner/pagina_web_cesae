Nome: Indigo Bordados
Tema: Um site minimalista pessoal para vendas dos meus bordados, com exposição da minha coleção e opção de compra.
Tecnologias utilizadas: HTML5 + CSS3 + Bootstrap 5 + Google Fonts + Iconify/Bootstrap Icons + JavaScript puro + ficheiros locais.
Funcionalidades principais: O site apresenta navegação responsiva entre páginas, uma coleção organizada de produtos, um formulário completo para encomendas, identidade visual consistente com tipografias personalizadas e um footer informativo presente em todas as páginas. O layout adapta‑se a diferentes dispositivos e inclui pequenos scripts para interações básicas, garantindo uma experiência simples, funcional e profissional.
Eventuais limitações: no meu formulário o utilizador não possui dados sobre: valor da compra, frete e não vai conseguir finalizar.
Ideias Futuras: Aprimorar as opões de imagens, com outras imagens diferentes do mesmo item, melhorar a pagina de vendas, melhorar a primeira pagina, com videos integrados.
